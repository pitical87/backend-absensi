PRINSIP
-------
1. Dokter TIDAK PERLU jadwal_shift untuk absen
2. Dokter bisa absen masuk-pulang beberapa kali per hari (multi-sesi)
3. Tidak ada kalkulasi status (Tepat Waktu/Terlambat), bintang, atau durasi
4. Hanya profesi "Dokter" yang mendapat perlakuan ini
5. Izin aktif TETAP memblokir dokter (sama seperti pegawai lain)
6. Rekap bulanan tampilkan jumlah sesi per hari untuk dokter

========================================================================
  ALUR ABSEN DOKTER
========================================================================

Absen Datang:
  User klik "Absen" → tipe = 'datang'
  → Cek GPS radius                    ✓ (sama)
  → Cek record terbuka (belum pulang) ✓ (sama)
  → Cek shift_id (skip untuk dokter)  ✓ (BARU)
  → Cek izin aktif                    ✓ (TETAP BERLAKU)
  → Tanggal = hari ini                 ✓ (BARU, tanpa shift)
  → Cek duplikat (skip untuk dokter)  ✓ (BARU, multi-sesi)
  → Status & bintang = null           ✓ (BARU)
  → Simpan record                      ✓ (sama, field null)
  → Tidak ada notifikasi keterlambatan ✓ (BARU)
  → Selesai

Absen Pulang:
  User klik "Absen" → tipe = 'pulang'
  → Cek GPS radius                     ✓ (sama)
  → Cari record terbuka                ✓ (sama)
  → Jika tidak ada + dokter: error     ✓ (BARU)
  → Jika tidak ada + bukan dokter: auto-create ✓ (sama)
  → Durasi & bintang = null            ✓ (BARU)
  → Update record                      ✓ (sama)
  → Selesai
