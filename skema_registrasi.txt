================================================================================
D. API ENDPOINTS
================================================================================

─── PUBLIC (Tanpa Auth) ──────────────────────────────────────────────────────

1. POST /api/mobile/register
   Fungsi: Pegawai mendaftar akun baru

   Request Body:
   {
     "nama_lengkap": "Budi Santoso",
     "nip_atau_nik": "198501012010011001",
     "no_hp": "081234567890",
     "email": "budi.santoso@rsudmerauke.go.id",
     "password": "secret123",
     "password2": "secret123"
   }

   Response 201:
   {
     "sukses": true,
     "pesan": "Pendaftaran berhasil. Menunggu verifikasi dari kepegawaian."
   }

   Response 422 (Error):
   {
     "sukses": false,
     "pesan": "Email sudah terdaftar."
   }

   Catatan:
   - Status awal: status_verifikasi = 'pending', status = 'nonaktif'
   - Pegawai belum bisa login sampai disetujui admin

───────────────────────────────────────────────────────────────────────────────


─── ADMIN (Butuh Auth Admin) ─────────────────────────────────────────────────

2. GET /admin/registrasi
   Fungsi: Halaman daftar permintaan registrasi

   Query Parameters:
   - q         : Search nama/email
   - status    : Filter status (pending/disetujui/ditolak)
   - page      : Halaman pagination

   Return: View blade admin/registrasi/index.blade.php

───────────────────────────────────────────────────────────────────────────────

3. GET /admin/registrasi/data
   Fungsi: Data AJAX untuk tabel registrasi (pagination)

   Query Parameters:
   - q, status, page

   Response JSON:
   {
     "sukses": true,
     "total": 10,
     "dari": 1,
     "sampai": 5,
     "halaman": 1,
     "totalHal": 2,
     "tbody": "<tr>...</tr>",
     "paginasi": "<div>...</div>"
   }

───────────────────────────────────────────────────────────────────────────────

4. GET /admin/registrasi/{id}
   Fungsi: Detail data registrasi + form proses

   Response JSON:
   {
     "sukses": true,
     "registrasi": {
       "id": 1,
       "nama_lengkap": "Budi Santoso",
       "nip": "198501012010011001",
       "nik": null,
       "no_hp": "081234567890",
       "email": "budi.santoso@rsudmerauke.go.id",
       "created_at": "2026-08-08 10:00:00"
     },
     "master": {
       "unit": [...],
       "sub": [...],
       "profesi": [...],
       "jabatan": [...],
       "kategori_jabatan": [...],
       "posisi": [...]
     }
   }

───────────────────────────────────────────────────────────────────────────────

5. POST /admin/registrasi/proses
   Fungsi: Approve atau tolak registrasi

   Request Body:
   {
     "id": 1,
     "aksi": "setujui",  // atau "tolak"
     "unit_kerja_id": 1,
     "sub_unit_id": 2,
     "profesi_id": 1,
     "jabatan_kategori": "Kepala Bidang",
     "jabatan_id": 5,
     "posisi": "Kepala",
     "status_pegawai": "PNS",
     "seksi_pembina_id": null,
     "shift_id": 3,
     "atasan_id": [10, 11],
     "catatan": ""
   }

   Response 200 (Setuju):
   {
     "sukses": true,
     "pesan": "Registrasi disetujui. Akun pegawai telah aktif."
   }

   Response 200 (Tolak):
   {
     "sukses": true,
     "pesan": "Registrasi ditolak."
   }

   Response 422 (Error):
   {
     "sukses": false,
     "pesan": "Unit kerja wajib dipilih."
   }

   Catatan:
   - Jika 'setujui': update semua field + status_verifikasi='disetujui' + status='aktif'
   - Jika 'tolak': status_verifikasi='ditolak' + catatan_verifikasi diisi

================================================================================
I. VALIDASI & ATURAN
================================================================================

1. NIP/NIK:
   - Wajib diisi salah satu (NIP atau NIK)
   - NIP: 18 digit (format NIP nasional)
   - NIK: 16 digit (format KTP)
   - Harus unik di tabel users

2. Email:
   - Wajib unik
   - Format valid email

3. Status Verifikasi:
   - Default: pending
   - Hanya admin yang bisa mengubah
   - Bisa diubah ke: disetujui atau ditolak

4. Approve:
   - Semua field kepegawaian wajib diisi
   - Shift wajib dipilih
   - Atasan wajib dipilih minimal 1

5. Tolak:
   - Catatan wajib diisi (alasan penolakan)
